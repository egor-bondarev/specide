## Поведение системы

При получении события изменения статуса сервис уведомлений определяет владельца заявки, проверяет его настройки и создает push-уведомление.

## Контракт события

```json
{
  "eventId": "evt-101",
  "applicationId": "app-42",
  "status": "approved"
}
```

## Обработка ошибок

- Повторное событие с тем же eventId игнорируется.
- При недоступности push-провайдера событие остается доступным для повторной обработки.
- Отсутствующий push-токен не влияет на обновление статуса заявки.
